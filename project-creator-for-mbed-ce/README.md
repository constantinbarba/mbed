# Project Creator for Mbed CE

A streamlined tool for VS Code that simplifies the creation and management of Mbed Community Edition (CE) projects.

## Features

- **One-Command Setup**: Create a new Mbed CE project instantly.
- **Command Palette Integration**: Simply use `CTRL+SHIFT+P` and select **Mbed CE: Create new Project**.

## Requirements

- **VS Code**: Version 1.80.0 or higher.
- **Toolchain**: To build projects, you must have the Mbed CE toolchain installed on your system.

### Toolchain Installation Guide
For a step-by-step setup, please refer to the official [Getting Started Guide](https://mbed-ce.dev/getting-started/toolchain-install/) or follow the video tutorial below:
